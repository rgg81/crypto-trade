# Team 10 dynamic relative value: exact sign inversion

This candidate preserves the baseline's pair selection, hedge ratios, convergence diagnostics,
weekly schedule, sizing, and full organizer risk policy. Immediately after the baseline portfolio
is formed, it negates every non-flat target weight exactly. Execution remains next-open and all
fees, slippage, funding, and controls are unchanged.

The run is a strict sign test: if the selected spreads really mean-revert, betting on divergence
should be materially worse after costs. If inversion instead repairs the bear and weak-fold losses,
the baseline convergence sign is falsified. This diagnostic sits outside the finalist neighborhood
and makes no performance claim.
