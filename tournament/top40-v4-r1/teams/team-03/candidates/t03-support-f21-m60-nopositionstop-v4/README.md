# Team 03 position-stop ablation

This candidate is bit-for-bit identical to the strong 21-day state-gated signal in trial 3. It disables only the central eight-percent position stop.

The ablation is motivated by the completed trial packet: position stops forced 917 exits and about 1.14 million USDT of notional, including 130 exits in 2024H1. The time stop, volatility target, drawdown brakes, turnover throttle, state gate, symbol cap, gross cap, and net cap remain active.

The ablation succeeds only if fold and quarter breadth improve without sacrificing the existing drawdown, cost, turnover, long/short, and regime strengths.
