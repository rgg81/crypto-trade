# Team 02 crypto-breadth side-switch breakout: neighborhood center

This candidate narrows the prior breadth-gated repair to a single causal side switch. When more
than or exactly half of eligible native crypto coins have a positive completed sixty-three-day
return, only positive fast-breakout scores may trade. Below half, only negative scores may trade.
Removing the former 45–55% neutral band prevents both sleeves from remaining active during an
ambiguous aggregate transition, where the prior run retained its counter-regime losses.

The twenty-day channel, seven-day return confirmation, persistence rule, weekly Monday schedule,
and volatility-target-only policy remain unchanged. Total gross is reduced from 0.36 to 0.32 to
address the prior run's 22.2% maximum drawdown while leaving ample room above the annual-return
floor. The model uses only point-in-time pure-crypto bars and no hindsight calendar state.

This is the preregistered center of `t02-breadth-switch-weekly-neighborhood`. It is falsified if
base and doubled-cost Sharpe, the weak fold, and adjusted confidence do not improve, if drawdown
still exceeds 20%, or if long, short, or chop roles turn negative. It makes no performance claim.
