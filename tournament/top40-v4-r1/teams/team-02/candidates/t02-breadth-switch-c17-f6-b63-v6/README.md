# Team 02 binary-breadth formation neighborhood: 17-day / 6-day

This candidate is one of five fully preregistered local formation points: (14,5), (17,6),
(20,7), (24,9), and (28,10), where each pair is channel days and fast-confirmation days.
This point uses a 17-day channel and 6-day confirmation. The complete grid was frozen before
the first point was evaluated.

Every other behavior is held fixed at trial 6's superior design: a completed sixty-three-day
native-crypto breadth reading selects exactly one breakout side at a 50% threshold, targets refresh
weekly on Monday, total gross is 0.32, and only the 22% volatility target is enabled. No stablecoin,
TradFi, metal, index, calendar hindsight, or OOS observation enters the model.

The neighborhood is falsified if fewer than 70% of points have positive annual return and positive
doubled-cost Sharpe, if median doubled-cost Sharpe is below 0.50, or if no bracketed interior point
clears every finalist gate. This candidate makes no performance claim.
