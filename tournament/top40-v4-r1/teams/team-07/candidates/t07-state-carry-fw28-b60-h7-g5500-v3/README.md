# Team 07 persistent-state funding carry

This trial changes only the causal BTC state horizon and threshold from the repaired 28-day center.
Funding estimation, exposure-reducing idiosyncratic protection, gross budgets, seven-day cohort
averaging and organizer controls are unchanged.

The organizer evaluates directional regimes from a lagged 60-day BTC state. A 60-day, 10% model
state should therefore remain short-dominant through bear-market countertrend rallies, remain
long-dominant through bull pullbacks, and return to equal-sided carry in sustained chop. It does
not read the organizer label; it independently computes the completed BTC return available at the
decision boundary.

The trial is falsified if bear and chop Sharpe, 2022, and 2024H1 do not improve without sacrificing
cost resilience, turnover, or bootstrap confidence.
