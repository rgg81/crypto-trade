# Team 07 price-confirmed funding carry at z=0.25

This is one of five confirmation thresholds frozen together before any point is evaluated. Each
candidate ranks only causally settled funding, searches the lowest and highest funding halves, and
then requires a completed three-day cross-sectional residual trend before entry. A long must have
state at least 0.25 and a short must have state at most -0.25.

This remains carry rather than reversal: low-rate names are bought, high-rate names are sold, and
every emitted cohort must have strictly positive expected funding carry. Price determines whether
the carry is safe enough to enter; it never reverses the funding direction. BTC state budgets,
seven-day cohorts, exposure limits, and all organizer controls are fixed across the neighborhood.

The family is falsified if confirmed shorts still lose to price continuation, if too few broad
positions survive, or if any gain fails cost, fold, regime, role, or neighborhood robustness.
