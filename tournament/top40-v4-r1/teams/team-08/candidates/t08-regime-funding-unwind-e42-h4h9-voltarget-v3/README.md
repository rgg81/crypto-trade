# Team 08 four/nine-day holding extension

This candidate changes only the two cohort holding windows from 3/7 to 4/9 days. Funding
standardization, price confirmation, market-state selection, independent roles, position counts,
gross budget, and the volatility-only overlay remain fixed.

The proportional extension targets the third trial's narrow misses: 20.67 annual turnover and
40.0 basis points of gross edge per turnover. It is falsified if lower churn dilutes the funding
unwind faster than it saves costs.
