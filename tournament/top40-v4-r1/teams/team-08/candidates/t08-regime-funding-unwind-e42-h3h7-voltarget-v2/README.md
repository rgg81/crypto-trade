# Team 08 volatility-only control ablation

This candidate holds the funding signal, market-state split, position selection, cohort horizons,
and gross budget exactly fixed. It removes the position stop, cooldown, drawdown brake, and
turnover cap after the official second trial attributed 1,228 exits and substantial blocked
re-entry to those controls.

The only organizer overlay is a symmetric 20% volatility target. The trial tests whether control
churn—not the funding-unwind mechanism—is responsible for the weak net edge.
