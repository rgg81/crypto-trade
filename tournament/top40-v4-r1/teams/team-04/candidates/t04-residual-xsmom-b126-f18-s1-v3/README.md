# Team 04 short residual-momentum neighborhood: 18 days

This candidate is the 18-day point in the fully frozen 14, 18, 21, 24, and 28 day residual
formation grid. It keeps the 126-day causal beta estimate, one-day skip, balanced top and bottom
cohorts, weekly Monday schedule, 0.44 gross budget, and original full protective controls fixed.

The grid tests primary crypto research placing cross-sectional momentum in the two-to-four-week
region and reversal beyond one month. Every input is a completed pure-crypto bar; the model uses no
stablecoin, TradFi, metal, index, calendar hindsight, or OOS observation.

The neighborhood is falsified if fewer than 70% of points have positive annual return and positive
doubled-cost Sharpe, if median doubled-cost Sharpe is below 0.50, or if no bracketed interior point
clears every finalist gate. This candidate makes no performance claim.
