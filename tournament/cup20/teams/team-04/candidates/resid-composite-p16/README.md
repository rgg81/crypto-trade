# resid-composite-p16

`resid-composite` at rebalance phase 16 instead of 10, and nothing else changed.

Phase is a first-order axis, not a detail: a cadence-21 result run at one offset is a result about
that offset. Every offline sweep in this team's research reports a phase MEAN over all 21 offsets
for exactly that reason, and the offline phase dispersion of this shape's Sharpe is about +/-0.15.
This run measures one further offset on the organiser's own pipeline so the phase claim rests on
measured evidence rather than on a simulator, and so the declared neighbourhood's phase points are
not the first phases ever scored by the harness.
