# Lane seeds

Twelve organizer-written starting points, one per lane. A seed is a *mechanism template*: it states
the lane's idea in the least clever form that could work, so that a team's first official trial
measures the lane rather than the team's ability to guess a starting point, and so that every
improvement a team reports is measured against a common floor.

A seed is not a result, a claim, or a recommendation. Each team's first charged trial is its
unmodified seed, and the leaderboard publishes the distance between that trial and the team's
nomination.

None of these port a candidate from an earlier tournament. They are written from the lane mandates
and the shared toolkit.
