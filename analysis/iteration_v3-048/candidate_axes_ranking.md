## Candidate 1 — NEW universal engineered feature: `vol_normalized_ret_5d` (RECOMMENDED)

**Axis classification**: E.2 (NEW universal engineered feature, Category 2 composed)

**Mechanism**: Add `vol_normalized_ret_5d = ret_5d / (range_realized_vol_50 + ε)` to
V3_FEATURE_COLUMNS_TOP_N (14 → 15). Composed feature; canonical Sharpe-like ratio.
Encodes risk-normalized momentum: how unusual is this 5-day return given recent
volatility regime?

```python
def compute_vol_normalized_ret_5d(df: pd.DataFrame) -> pd.DataFrame:
    """Composed feature: ret_5d / (range_realized_vol_50 + epsilon).

    Past-only: ret_5d already shifts log_close by 15 bars (~5d at 8h).
    range_realized_vol_50 is computed in tail_risk_v3.add_tail_risk_v3_features
    via past-only rolling window. epsilon=1e-6 prevents zero-vol division.
    """
    df = df.copy()
    close = df["close"].astype(float)
    log_close = np.log(close.clip(lower=1e-12))
    ret_5d = log_close - log_close.shift(15)  # 15 bars * 8h = 5 days
    if "range_realized_vol_50" not in df.columns:
        df["vol_normalized_ret_5d"] = np.nan
        return df
    rv = df["range_realized_vol_50"].astype(float)
    df["vol_normalized_ret_5d"] = ret_5d / (rv + 1e-6)
    return df
```

**At every threshold, the OOS gain from blocking TRX SHORT in stressed regimes is

**Per `feedback_v3_strict_both_is_oos_baseline.md`**: this axis FAILS the BOTH-must-
