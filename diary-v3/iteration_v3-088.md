## 1. What was done — the re-architecture

- **Model**: ONE pooled `LGBMRanker(objective="lambdarank")` (LambdaMART) replaces the N per-symbol `LightGbmStrategy` instances — new module `src/crypto_trade/strategies/ml/cross_sectional.py` (1073 lines), new runner `run_cross_sectional_v3.py` (the legacy per-symbol `run_baseline_v3.py` is untouched).
- **Label**: a cross-sectional forward-return rank — within each 8h timestamp's cross-section, the H=3-bar (1-day) forward return is ranked and tercile-graded {0,1,2} — replaces the absolute `(2.0,1.0)`-ATR triple-barrier. The label is RELATIVE: market-wide moves cancel.
- **Universe**: a 22-symbol `XS_UNIVERSE` (non-v1/v2 Binance-USDT perps, IS-screened — all 22 cleared the T1 ≥1500-IS-row / ≥$2M-liquidity screen), the cross-section the pooled model ranks within. - **Features**: 13 features — the 14-feature /059 anchor stack minus `btc_ret_14d` (EDA T6: zero cross-sectional dispersion, identical for every symbol at a timestamp), each cross-sectionally rank-normalized at training time.
- **Position construction**: dollar-neutral tercile long-short, inverse-vol weighting within each leg, portfolio vol-targeting. Rebalanced every 8h bar. 0.1% turnover-based fee.
- **CPCV gap**: `XS_REQUIRED_GAP = 88 = (H+1)×N_symbols = (3+1)×22`, distinct from the legacy `REQUIRED_GAP = 66`.
- **Risk**: the legacy 7-gate v3 stack is intentionally ABSENT (brief Section 3.7 — re-introducing gates would confound the architecture measurement); three structural controls replace it (dollar-neutral construction, inverse-vol + vol-target, tercile diversification).
