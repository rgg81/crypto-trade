## Lessons

Four generalizable takeaways for future v3 iterations and skill-update PRs:

1. **Per-cell PBO/CSCV with cross-cell statistical aggregation, not cross-cell summation.** The next methodology-axis iteration must compute PBO per (sym, train_month, ensemble_seed) cell — i.e., one CSCV per Optuna study where the 50 trials within that study ARE 50 distinct strategies (their `trial_id`s are meaningful within the within-study Bayesian sampler trajectory). Then aggregate the ≈500 cell-level PBOs into a single number via Fisher's method (combine p-values from per-cell PBOs interpreted as null-hypothesis p-values) or median-of-PBOs. The consumer code MUST run CSCV `n_cells` times (≈500), not once on an aggregated parquet. This avoids the cross-cell `trial_id` semantic mismatch entirely. Persist per-trial OOF returns as already done in iter-v3/003 (the parquet is correct on the producer side); consume them via the per-cell pathway. This is Critic Recommendation #1 verbatim.

2. **Falsifier text must embed the methodology mechanism, not just numeric thresholds.** Brief Section 4.2 tertiary falsifier ("if `dsr.json["n_eff"]` is exactly 4 ... sub-fix #3 was not implemented") was technically averted by the shipped value of 1, but the spirit was violated — n_eff=1 is structurally the same kind of failure as n_eff=4 (rank tautology from a degenerate construction). Future falsifiers should specify "n_eff > min(N_cells, n_trials/N_cells)" or "PBO computed within a single cell's strategy axis must match within ±0.1 of the cross-cell aggregate". Numerical thresholds without mechanism descriptions are fragile to clever-but-wrong constructions. This is Critic Recommendation #2 verbatim.

3. **Pre-register a Phase 5.5 consumer-preserves-signal adversarial test** (separate from the producer-writes-correctly test). iter-v3/003's `tests/strategies/ml/test_oof_persistence.py` only tested the parquet write side (rows exist, columns correct, cardinality matches) — it did not test that the consumer pipeline preserves strategy-distinguishing signal. The next brief Section 3.6.1 should specify a synthetic adversarial test that constructs (a) a cell where 50 trials are DEEPLY OVERFIT vs (b) a cell where 50 trials are CLEAN, mixes them with the prescribed cross-cell aggregation, and asserts that PBO and n_eff distinguish them. If the prescribed aggregation cannot distinguish the synthetic mix-in, Phase 5.5 BLOCKs before backtest. This is Critic Recommendation #3 verbatim.

4. **v3 dead-paths catalog (third entry):**
   - **iter-v3/003 — methodology repair via cross-cell `trial_id` aggregation (BCH+MKR+LDO+TRX universe).** NO-MERGE due to criterion 22 fail (n_eff=1 from a degenerate strategy axis from cross-cell `groupby("trial_id").sum()`) + Critic Checks 3, 6, 8 FAIL. Root cause: brief Section 2.4 pseudocode prescribed `groupby(["trial_id", "candle_open_time_ms"])["oof_return"].sum()` aggregating across (sym, train_month, ensemble_seed) cells where Optuna's `trial_id` has only within-study semantics — each `optimize_and_train` calls `optuna.create_study(sampler=TPESampler(seed=seed))`, so `trial_id=0` from cell (BCH, 2023-01, seed=42) is a different model than `trial_id=0` from cell (MKR, 2023-02, seed=123). Summing across ≈10 unrelated models per `trial_id` produces noise; the resulting (50 × 5359) matrix is near rank-1 by construction; n_eff=1 follows mechanically. The (45 × 50) PBO strategy axis is degenerate (PBO=0.0 from a meaningless ordering, not from real cross-strategy generalization). **The implementation faithfully reproduced what the brief specified; the brief itself encoded the methodology error.** Future per-trial-OOF iterations must use per-cell CSCV with cross-cell statistical aggregation (Fisher's method or median-of-PBOs across the ≈500 cell-level PBOs), not cross-cell summation. The universe (BCH+MKR+LDO+TRX) is NOT on the dead-paths catalog; the iteration's failure was methodology-design, not universe-level. The `trial_oof_returns.parquet` from iter-v3/003 (78M rows, 50 trial_ids, schema correct) CAN be re-used in iter-v3/004 for the per-cell consumer pathway — no rebuild needed.
